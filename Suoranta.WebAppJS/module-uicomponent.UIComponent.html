Class: UIComponent

uicomponent.UIComponent()

JavaScript component that binds its properties to an UI element.

Constructor

new UIComponent()

Constructs UIComponent
Properties:
Name Type Description
model object DTO object from which property values are read and set. Can contain only the values that should be updated.

Methods

_bound(name, target, value, placeholder, formatter)

Create a new property (binding) to which UI element is bound. @protected
Parameters:
Name Type Description
name string Name of the property.
target HTMLElement | jQuery | string The target element to update. Provide id if the DOM is not ready.
value any The default value.
placeholder string Optional placeholder text to display when the actual value is not available.
formatter function Optional function to format the display value.

init(defineProperties)

Initializes bindings. Bound input elements must be present in the DOM when this method is called.
Parameters:
Name Type Description
defineProperties boolean Should the instance have properties through which UI values can be directly accessed defined on it. The alternative of defining properties in code is better for a few properties as that makes their existence explicit. The binding system does not need the properties, so they can also be left undefined (in which case values can be accessed through this.#bindings and the HTML elements/widgets).

resetValues()

Resets bound values to their defaults.
