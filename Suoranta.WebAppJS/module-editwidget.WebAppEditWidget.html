Class: WebAppEditWidget

editwidget.WebAppEditWidget(actionTemplate, parameterPlaceholder, closeCallback)

new WebAppEditWidget(actionTemplate, parameterPlaceholder, closeCallback)

Constructs EditWidget.
Parameters:
Name Type Description
actionTemplate string Template of the action URI returning partial view to display. The returned view must contain element 'PartialContainer' as its visual root and script block with id 'KendoScripts' for widget initializers to be executed. Should be left null if @see {openURI} is used to start the editor.
parameterPlaceholder string Substring within @see {actionTemplate} that should be replaced with parameterValue of @see {open}. The default is '_i_d_'. Can be left null if @see {openURI} is used to start the editor.
closeCallback function parameterValue of @see {open} is passed to this callback. Callback should at least re-read value of the edited entity.
